# Kinetic

A private, local-first weekly training planner. No account or database is required: workouts and hydration progress are stored in browser `localStorage`.

## Run locally

```bash
npm install
npm run dev
```

## Build and deploy

```bash
npm run build
```

Deploy the generated `dist` directory to GitHub Pages, Netlify, or any static host.

## Moving your data

Use **Data & backup → Export current** to download a JSON backup. The same dialog accepts backups and plans generated by Gemini. **Copy prompt** creates a ready-to-paste prompt that asks Gemini for the exact JSON structure Kinetic supports.

Browser storage is specific to a browser and site URL. Export a backup before clearing browser data or moving the app to a different domain.
